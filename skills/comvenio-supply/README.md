# Küche und Versorgung

Dieser Skill hilft Ihrem KI-Assistenten bei Gerichten, Getränken, Allergenen,
Speisekarten, Preisen und Einkaufslisten.

Beispielwünsche:

- „Erstelle aus dieser Getränkeliste eine Karte und zeige sie mir zuerst.“
- „Nutze vorhandene Rezeptvorlagen für unser Grillfest.“
- „Berechne die Einkaufsliste für 250 Gäste.“

Der Assistent nutzt vorhandene Vorlagen, prüft Allergene und zeigt Karte oder
Einkaufsliste vor weitreichenden Änderungen. Veröffentlichung, Löschen,
Preisänderungen und vollständiges Ersetzen benötigen Ihre Bestätigung.

Das CLI führt keine zusätzliche versteckte KI-Generierung aus; der Assistent
komponiert die Inhalte nachvollziehbar aus den belegten Daten.
