# Öffentliche Vereinswebsite

Dieser Skill hilft Ihrem KI-Assistenten, die öffentliche Vereinswebsite zu
strukturieren, zu gestalten, als Vorschau zu prüfen und kontrolliert zu
veröffentlichen.

Beispielwünsche:

- „Baue eine Startseite mit News, Terminen und Kontakt.“
- „Passe Farben und Typografie an unseren Verein an.“
- „Prüfe unsere Website auf Desktop und Mobilgerät.“

Der Assistent liest das aktuelle Schema, erstellt eine Vorschau und prüft das
Ergebnis vor dem Anwenden. Live-Schaltung, Vollersatz und weitreichende
Designänderungen benötigen Ihre eindeutige Bestätigung.

Die Anbindung einer eigenen Domain erfolgt derzeit in der Comvenio-Web-App und
wird nicht durch einen erfundenen CLI-Befehl ersetzt.
