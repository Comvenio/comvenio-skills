# Sponsoring

Dieser Skill hilft Ihrem KI-Assistenten, Sponsoren, Sponsoringpakete,
Vertragsstände, Laufzeiten, Logos und Veranstaltungszuordnungen zu pflegen.

Beispielwünsche:

- „Lege die Muster GmbH mit Logo als Sponsor an.“
- „Hinterlege die Konditionen für 2027 als neue Vertragsversion.“
- „Ordne das Gold-Paket unserem Sommerfest zu.“

Der Assistent bewahrt ältere Vertragsstände und behandelt Vertragsdokumente
vertraulich. Kündigungen, Löschungen sowie Änderungen an Preis oder Laufzeit
benötigen Ihre eindeutige Bestätigung.

Dieser Skill deckt das lokale Vereinssponsoring ab, nicht einen globalen
Anzeigenmarktplatz oder Plattformabrechnungen.
