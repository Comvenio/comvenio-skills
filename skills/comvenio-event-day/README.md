# Veranstaltungstag

Dieser Skill hilft Ihrem KI-Assistenten, einen Veranstaltungstag als Ganzes zu
prüfen: Bereiche, Helfer, Programm, Aufgaben, Räume, Speisekarten, Dateien,
Sponsoren und Geländeplan.

Beispielwünsche:

- „Prüfe, ob für morgen beim Sommerfest alles vorbereitet ist.“
- „Zeige mir offene Aufgaben und fehlende Bereichsleitungen.“
- „Erstelle nach dem Fest eine geordnete Abschlussliste.“

Der Assistent liefert zuerst eine belegte Übersicht. Änderungen werden je
Fachbereich einzeln vorbereitet und geprüft. Kritische oder öffentliche
Aktionen benötigen Ihre Bestätigung.

Es gibt keinen Alles-auf-einmal-Rollback. Eine allgemeine automatische Nachricht
an sämtliche Helfer ist derzeit nicht Teil des CLI.
