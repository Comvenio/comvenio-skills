# Helferkoordination

Dieser Skill unterstützt Ihren KI-Assistenten bei Helfereinteilung,
Bereichsleitungen und den dazugehörigen Aufgaben einer Veranstaltung.

Beispielwünsche:

- „Zeige mir, welche Bereiche noch keine Helfer haben.“
- „Mache Lisa zur Leitung der Bar und gib ihr die Kassenübergabe.“
- „Verteile die vorhandenen Helfer als Vorschlag auf Bühne, Bar und Küche.“

Der Assistent zeigt Mitgliedsnamen, Bereiche und Aufgaben vor jeder Änderung.
Komplettes Leeren, Ersetzen von Helfern oder größere Aufgabenpakete benötigen
Ihre Bestätigung.

Comvenio kann über diesen Skill keine unbekannten Verfügbarkeiten erraten und
derzeit keine allgemeine Nachricht automatisch an alle Helfer senden.
